Connect ProfileBar

This extension asks the ProfileBar app on your Mac to open pages in another Chrome profile.

  1. Install ProfileBar 1.4 or later.
  2. Open ProfileBar once so it can connect to Chrome.
  3. Come back here and choose Check again. If ProfileBar is still not found, restart Chrome.
Get ProfileBar

Install this extension in each Chrome profile you move tabs from. To keep a group’s name and colour, install it in the destination profile too.
